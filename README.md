# 二维点质量轨迹仿真与实验分析工具

这是一个使用 Python 标准库编写的二维网格导航仿真项目。程序让一个点质量在有限大小的二维网格中移动，并比较随机策略和贪心策略的行为。

## 项目功能

- 表示二维网格中的位置和目标位置
- 支持上、下、左、右和停留动作
- 限制越界移动，并检查非法动作
- 记录每个回合的轨迹
- 提供随机策略和贪心策略
- 支持设置随机种子，保证实验可以复现
- 支持设置最大步数
- 批量运行多个回合
- 统计成功率、平均步数和最终距离等指标

## 环境要求

- Python 3.12 或更高版本
- 只使用 Python 标准库
- 不需要安装 NumPy、PyTorch 或其他第三方包

## 运行方法

在项目目录中打开终端，并激活虚拟环境：

```bat
.venv\Scripts\activate
```

运行程序：

```bat
python main.py
```

## 实验设置

程序可以设置以下参数：

- 起点位置
- 目标位置
- 网格宽度和高度
- 使用的策略
- 实验回合数
- 随机种子
- 每回合最大步数

其中，随机策略从可用动作中随机选择；贪心策略每一步选择能够减小当前位置与目标位置曼哈顿距离的动作。

## 指标说明

- `successes`：成功到达目标的回合数
- `success_rate`：成功回合数除以总回合数
- `average_steps`：所有回合的平均步数
- `average_final_distance`：所有回合结束时的平均目标距离
- `successful_average_steps`：成功回合的平均步数
- `shortest_steps`：最短回合步数
- `longest_steps`：最长回合步数

## 项目局限

当前项目是二维网格导航仿真，不包含真实物理动力学、图像观测、神经网络或强化学习训练。
