# py_project：二维网格策略对比实验

使用 Python 模拟智能体在二维网格中的移动，比较贪心策略和随机策略，记录是否到达目标、执行步数、最终距离和完整位置轨迹。适合学习状态、动作、策略、回合终止条件与随机实验的可重复性。项目没有训练过程，也不依赖机器学习框架。

## 运行方法

使用 Python 3（本次实测版本为 Python 3.12.9），仅依赖标准库，无需安装第三方包。

```bash
git clone https://github.com/zxlin1650-gif/py_project.git
cd py_project
python main.py
```

Windows 也可以使用 `py main.py`。若终端中文编码异常，可以运行 `python -X utf8 main.py`。

## 参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| width、height | 7、7 | 坐标范围均为 0～6，无障碍物 |
| start | {"x": 0, "y": 0} | 起点 |
| goal | {"x": 3, "y": 2} | 目标 |
| seed | 两种策略均为 1 | 每个回合各自创建随机数生成器 |
| max_steps | 两种策略均为 30 | 最多执行的动作数量 |

动作包括 RIGHT（x 加 1）、LEFT（x 减 1）、UP（y 加 1）、DOWN（y 减 1）和 STAY（不动）。越界坐标会被截断到地图边界；原地停留和撞到边界也计为一步。轨迹包含起点，因此其长度为执行步数加 1。

## 策略与程序结构

- `distance`：计算当前位置到目标的欧氏距离。
- `move`：根据动作生成新状态，并限制坐标范围，不修改传入状态。
- `random_policy`：从固定顺序的五个动作中等概率随机选择，不使用当前位置或目标进行决策。
- `greedy_policy`：优先沿坐标差绝对值较大的轴向目标移动，差值相同且水平方向尚未到位时优先水平移动。该策略不使用随机数。
- `run_episode`：复制起点，创建 `random.Random(seed)`，循环选择动作、更新状态、记录轨迹，直到到达目标或耗尽步数。
- `main`：分别运行两种策略并打印结果。

成功表示最终位置等于目标；失败表示本回合结束时仍未到达目标，不是程序异常。起点等于目标时不进入循环，成功且步数为 0。此时仍应传入正整数步数上限；当前代码对小于 1 的上限会抛出 ValueError。

| 策略 | 成功 | 步数 | 最终位置 | 最终距离（两位小数） |
| --- | --- | --- | --- | --- |
| greedy_policy | True | 5 | (3, 2) | 0.00 |

